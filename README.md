# เผยแพร่ให้ใช้ได้โดยไม่ล็อกอิน Google + ลิงก์สั้น

## 1) เผยแพร่เว็บแอปแบบสาธารณะ (ใน Apps Script)
1. Deploy → New deployment → เลือกประเภท **Web app**
2. ตั้ง **Execute as: Me** และ **Who has access: Anyone** แล้วกด Deploy (ครั้งแรกจะขออนุญาตสิทธิ์)
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`
4. เปิดแอปด้วยบัญชีเจ้าของชีต ไปที่ **หลังบ้าน** แล้ว
   - ตั้ง **รหัสเข้าใช้งาน** (ผู้ที่ไม่ล็อกอิน Google ต้องใส่รหัสนี้ ถ้ายังไม่ตั้ง ผู้ที่ไม่ล็อกอินจะเข้าไม่ได้เลย)
   - กด **ติดตั้งตัวตรวจจับการแก้ชีต** (ให้การแก้ใน Google Sheets ปรากฏในหน้าเว็บภายในไม่กี่วินาที)

## 2) แก้โค้ดภายหลังโดยลิงก์ไม่เปลี่ยน
Deploy → **Manage deployments** → ไอคอนดินสอของ deployment เดิม → Version: **New version** → Deploy
(อย่ากด New deployment ซ้ำ เพราะจะได้ URL ใหม่) หน้าเว็บทุกหน้าโหลดโค้ดชุดใหม่ทันทีที่เปิดครั้งถัดไป

## 3) ลิงก์สั้นชื่อ borisatkongraonayoo + ซ่อนแบนเนอร์ของ Apps Script
อัปโหลดไฟล์ `index.html` ในโฟลเดอร์นี้ไปที่เว็บโฮสต์ฟรีอย่างใดอย่างหนึ่ง (แก้ค่า `EXEC` ในไฟล์ให้เป็น URL ข้อ 1 ก่อน)
- Cloudflare Pages → ตั้งชื่อโปรเจกต์ `borisatkongraonayoo` ได้ลิงก์ `https://borisatkongraonayoo.pages.dev`
- Netlify (Drop) → ตั้งชื่อไซต์ `borisatkongraonayoo` ได้ลิงก์ `https://borisatkongraonayoo.netlify.app`
- GitHub Pages → ต้องมีบัญชี GitHub ชื่อ `borisatkongraonayoo` ได้ลิงก์ `https://borisatkongraonayoo.github.io`

ชื่อต้องยังไม่มีคนใช้ ถ้าถูกใช้แล้วต้องเปลี่ยนชื่อ หน้าเว็บนี้ฝังแอป Apps Script ไว้ในกรอบเต็มจอ แบนเนอร์ "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script" รายงานว่าไม่แสดงเมื่อฝังแบบนี้ (ต้องลองกับ deployment จริงเพื่อยืนยัน)
ใส่ `?page=claims` ท้ายลิงก์เพื่อเปิดหน้านั้นโดยตรง (`tech`, `parts`, `cosco`, `claims`, `warranty`, `onsite`)

## ข้อควรระวัง
- แอปทำงานด้วยสิทธิ์เจ้าของชีตเสมอ ใครมีรหัสเข้าใช้งานก็อ่านและแก้ข้อมูลได้ จึงควรใช้รหัสยาวและเปลี่ยนเมื่อคนเก่าออกจากงาน (เปลี่ยนรหัสแล้วทุกเครื่องต้องใส่ใหม่)
- เบราว์เซอร์บางตัวบล็อกการจำข้อมูลของเว็บที่ฝังอยู่ในกรอบของเว็บอื่น (Safari และโหมดส่วนตัวของบางเบราว์เซอร์) จึงอาจต้องใส่รหัสเข้าใช้งานทุกครั้งที่เปิด ธีมที่เลือกและข้อมูลที่จำไว้ก็อาจไม่ถูกจำ
